One original one-line excuse for skipping a pointless meeting: your
calendar books you into a meeting with yourself — "cry in the car park" —
and the turn is that it is the only meeting today with a clear agenda.
One concrete scene, one reversal, one landing line. No bad wifi, no cat,
no dentist.

## Run it

```sh
python3 main.py
```

This writes the excuse to `/output/entry.txt` (one line, under 200 characters,
UTF-8). Running it twice produces byte-identical output.
